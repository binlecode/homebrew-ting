# homebrew-ting

Official Homebrew tap for [ting (听)](https://github.com/binlecode/ting) — an agent-first multi-source media engine with a terminal face.

## Installation

```sh
brew tap binlecode/ting && brew install ting
```

Or direct one-line installation:

```sh
brew install binlecode/ting/ting
```

## Update

```sh
brew upgrade ting
```
