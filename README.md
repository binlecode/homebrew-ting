# homebrew-ting

Official Homebrew tap for [ting (听)](https://github.com/binlecode/ting) — an agent-first multi-source media engine with a terminal face.

## Installation

```sh
brew install binlecode/ting
```

Or tap explicitly:

```sh
brew tap binlecode/ting
brew install ting
```

## Update

```sh
brew upgrade ting
```
